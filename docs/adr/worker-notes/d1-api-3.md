Inbox:

- The h1 is `headline`; for an open batch it is the group headline. The title moves to a small line above it (`decision-title`). Queue rows read `headline`.
- The track record bolds `{k} of {n}` from the numbers, then `outcome (pct%)`. Below 5 cases it shows `basis`.
- The policy line comes from `learnable`, up front. "Propose always auto-run" shows only when `ok`; a 422 from the endpoint replaces the line.
- The `claim_busy` message goes through `explain()`. `settle()` already refetches the inbox on error, so the fresh `move` locks Approve. Unit test: `InboxPage.test.tsx` uses `holdRun`. No two-tab e2e.
