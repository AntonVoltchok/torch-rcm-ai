## What is not faithful, said plainly

- **Snapshots are static.** Only the tour's "Try it" buttons, the sidebar links and the screen picker change what you see. Any other control shows a note that the mock holds snapshots.
- **Run streaming is replayed.** The first two frames of each run pane are real intermediate captures. After that, the final captured pane is revealed step by step. The steps, labels and "What changed" numbers are the captured ones, but the timing is the mock's.
- **Two `<select>` values are restored in the mock.** These are "Signed in as" (Dr. Morgan or Dr. Lee) and the Activity agent filter. React keeps a controlled select's value as a property, not markup, and the first captures missed it. `snap.cjs` and `mutate.cjs` now sync it, so a re-capture won't need the patch.
- **The Settings Try-its show one hover state.** Status check → Runs without review gives 41 → 41. The live preview isn't recomputed for other rows.
- **No Thursday screen tours.** Thursday appears only at the end of the main tour.
