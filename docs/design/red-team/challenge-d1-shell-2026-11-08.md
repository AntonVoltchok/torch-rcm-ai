# Red team: d1-shell phase 1 calls

1. **Panel wrapper: agree with A, with one change.** Merge it with call 2 into a single typed `staticData.chrome = { panel: boolean, header: 'full' | 'slim' | 'none' }`. Read it from the leaf match (`useMatches({ select: (m) => m.at(-1)?.staticData.chrome })`) with a documented default. Then the shell has one route-driven switch, not two, and no route-name checks hide in `RootLayout`. The panel should be the scroll container (`min-h-0 overflow-auto`), so a long page doesn't scroll the KPI header away or create two scrollbars.

2. **Which header where: agree with A.** The strip is the spine, and step 5 needs it on every page. Route-driven through the same `chrome.header` key (call 1). The active cell on `/claims` must come from the validated search (`useMatch({ from: '/claims', shouldThrow: false })?.search.status`), not from a prop a page passes in, so the URL stays the truth. Render it as `aria-current="true"` on that link as well as a ring. Both variants keep `<section aria-label="Claim pipeline">` and `Label N` link names: steps 1, 3, 5 and 8 select by them.

3. **"Yours" card: agree with A, and make the units honest.** `inbox_open` has to match the Inbox nav badge. Two places showing different "yours" numbers is the first thing I'd catch. But "12 items | 11 claims | 88 claims" next to "107 open" invites adding them up, and D1's tooltip says they add up. Drop that tooltip. Print the unit beside every big number. Label the payer sub "`money(cents)` billed, waiting on a reply", because `MoveCount.cents` is billed, not expected. If you want the practice-wide figure, show `moves.practice.count` as a server number ("14 with the practice"), never as a difference the client computed.

4. **⚑ need-action link: agree with A, with two fixes.** Render `strip.flagged_count`, not `flaggedTotal()`, which sums tiles on the client while the server already sends the number. And don't colour it `bad`/risk red: D1 keeps red for money at risk and root cause `ours`, and `needs_action` is neither. Use ink or act with the flag glyph.

5. **Persona switcher: agree with a native select, but keep the role visible.** Four users don't fit a 208px segmented well, and `shared.ts` drives `Switch user`, so a native select is right. Showing the name only loses the fact the product hinges on ("Dr. Morgan signs", owner-only routes). Keep the role in the option text, or as a line under the control. Keep "(demo)" visible, so nobody reads it as real auth.

6. **Outage: hybrid.** Use D1's sidebar line as the global indicator, but don't make it the only place the fact appears. The `portal_outage` scenario is a demo point (a failed step becomes an Inbox item), and a 12px grey line in the sidebar foot hides the reason Dana is looking at that item. Put a one-line inline note where it matters: on Inbox items and claims for the down payer (server-provided, e.g. from the item's reason or world payers). Drop `title` as a carrier, since it isn't reliably announced. `role="status"` on a sidebar that never remounts announces only on change, which is correct: "once per screen" won't happen, and shouldn't.

7. **Type scale: agree, with two conditions.** Define line-heights with the sizes (`--text-sm--line-height` etc. in Tailwind v4), because D1's 1.45 body leading is half its look and `body` is 1.35 today. And bumping 11→12 and 13→14 under every feature reflows tables owned by sessions that haven't run yet (Claims, Ledger, Eligibility). Before hand-over, screenshot all ten routes at 1280×800 and list the overflows, so d1-rest inherits a list and doesn't find them later.

8. **Colour tokens: agree with keeping the names, but not with two names for one value.** Make `--color-acc: var(--color-act)`, mark `acc` deprecated in a comment, and give d1-rest a codemod to remove it. Otherwise "which one do I use?" comes up in every review. The bigger issue is a collision: `warn` takes D1's amber while `practice` is amber, so "Agents paused" and outage warnings will read as "yours". Give `warn` a hue distinct from `practice`, or render warnings neutral plus an icon. Remapping `bad` to risk red also turns every error ("Advance failed", retry states) into "money at risk". Check each `text-bad` use.

## Missed

- **Numbers the server didn't compute, in files this session owns.** `PipelineStrip` renders `openTotals()`, `arTotals()` and `flaggedTotal()`, client sums of tiles, while `Strip` already sends `open_count`, `open_cents`, `ar_count`, `ar_cents` and `flagged_count`. Switch to the server fields and delete the selectors. `tileFor()` invents a zero tile when a status is missing, so it renders 0 the server never sent. Show "—" instead, as the component's own doc promises.
- **The D1 sidebar status line** ("This week agents ran N on their own, M came to you") has no server field. Either source it from `GET /agents/status` or `nav_badges.activity`, or drop it. Don't port it from the prototype's `s.week`.
- **The Denied tally** must come from `tile.by_holder` (`mine`, `count`), never from client bookkeeping like D1's `handed`/`LANDS` map. Its `role="img"` sits inside the "Denied 5" link. Keep the link's `aria-label` exactly `Denied 5`, because e2e step 5 matches it `exact`, and put the holder split in visible or `sr-only` text outside the link name.
- **Reduced motion: nothing in `apps/web/src` handles `prefers-reduced-motion`.** Add a global reduce rule in `styles.css`, as D1 has. Use `motion-safe:` for the spinner, the pulse, the rod slide and the tick recolour. Any JS-timed animation checks `matchMedia` first.
- **1280px.** D1 is drawn at 1440 with a fixed 744px KPI column. At 1280 the main area is about 1072px, which leaves the pipeline card about 280px for a 4-column grid of nowrap cells ("Accepted 12"), and that overflows. Use fractional columns (for example `3fr 2fr`) or let the cell grid wrap. The slim pipe (9 cells + total, 22px gaps) is near the limit at 1072px too. Add a Playwright check at 1280 that `scrollWidth <= clientWidth` on `main` for every route.
- **Accessibility.**
  - KPI baton glyphs ("Baton at you") are decoration next to a labelled number; mark them `aria-hidden`.
  - The to-scale bar is redundant with the cell links; make it `aria-hidden`, or give it a label that carries the counts.
  - KPI numbers patched from `meta.counts` must not sit in live regions.
  - Add a skip-to-content link: the sidebar puts nav, agent status, switcher and clock before `main`.
- **URL as truth, edge case.** Location lives in localStorage and is part of every list query key. It's defensible as tenant scope, but say so in a line, or a reviewer will flag it against the rule.
